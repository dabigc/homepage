Learn more about [Teamarr](https://github.com/Pharaoh-Labs/teamarr).

Teamarr is a dynamic EPG generator and event channel management tool for IPTV stacks.

The widget displays active channel count, channel group count, last automation run time, and average run duration.

```yaml
widget:
  type: teamarr
  url: http://teamarr.host.or.ip:9195
```
